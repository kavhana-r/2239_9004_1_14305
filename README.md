 MintMatrix – Multi-Currency Budget Analytics Platform

📌 Project Overview

MintMatrix is a full-stack web application designed to simplify personal finance management through multi-currency budget tracking and financial analytics.

It helps users manage income, expenses, transactions, and financial activities in one centralized platform.

✨ Features

- User authentication and secure access
- Income and expense management
- Add, edit, view, and delete transactions
- Multi-currency transaction support
- Transaction categorization
- Financial data management
- Responsive user interface
- Backend API integration
🛠️ Tech Stack

Frontend
- React.js
- JavaScript
- HTML5
- CSS3
- Ant Design
- Redux
- Axios

Backend
- Java 17
- Spring Boot 3.2.5
- Spring Security

Database

⚙️ Installation and Setup

 1. Clone the Repository

```bash
git clone https://github.com/kavhana-r/2239_9004_1_14305.git
```

2. Backend Setup

```bash
cd backend
```

Run the Spring Boot application:

```powershell
.\mvnw.cmd spring-boot:run
```

3. Frontend Setup

Open a new terminal:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start the frontend:

```bash
npm start
```

🗄️ Database Configuration

This project uses MySQL as its database.

Configure your database connection details in the backend application configuration file before running the application.

Do not upload database passwords, API keys, or secret credentials to GitHub.
